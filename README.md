# LyricsX

Open-source lyrics visualizer for Windows. Shows the lyrics of whatever you're currently playing in Spotify as large, animated typography — in time with the music.

## Quick Start

1. **Start Spotify** and play a song.
2. Double-click **`start.bat`** (or run `node server.js` in a terminal).
3. Open **http://localhost:3000** in your browser.

No accounts. No login. No setup.

## Requirements

- Windows 10 or 11
- Node.js 22+
- Spotify Desktop App (or any media player visible in Windows media controls)

## Features

| Category | Options |
|----------|---------|
| **Typography styles** | Kinetic Words · Afterglow · Classic Stack · Karaoke · Minimal · Editorial · Typewriter · Poster · Pill Rail |
| **Backgrounds** | Plain black · Edge glow · Album-art blur · Soft aurora · Particles · Starfield · Film grain |
| **Color palettes** | Reference pink · Mint · Amber · Ice |
| **Fonts** | Auto · Plus Jakarta Sans · Inter · Fraunces · JetBrains Mono |

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `F` | Toggle fullscreen |
| `P` | Player screen |
| `S` | Settings screen |
| `L` | Lyrics screen |
| `Esc` | Back / exit fullscreen |
| `Space` | Play/pause (demo mode) |
| `← →` | Seek ±5s (demo mode) |

## Privacy

**Nothing leaves your computer** except the lyrics lookup request to [LRCLIB](https://lrclib.net). No analytics, no telemetry, no accounts.

LyricsX is not affiliated with Spotify or LRCLIB.  
Lyrics provided by [LRCLIB](https://lrclib.net) — a free, open lyrics database.
